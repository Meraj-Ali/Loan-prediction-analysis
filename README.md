# Loan Prediction Analysis using Machine Learning

A Machine Learning project that predicts loan approval status based on applicant demographic and financial information. This project includes data preprocessing, exploratory data analysis (EDA), feature engineering, visualization, and classification model building using Python and Scikit-learn.

**Project Overview**

The goal of this project is to analyze loan applicant data and build a predictive model that determines whether a loan application should be approved or rejected.

The project focuses on:

Data Cleaning
Exploratory Data Analysis (EDA)
Data Visualization
Feature Engineering
Machine Learning Classification
Model Evaluation
